# Yocto AI Skills

A collection of six reusable skills for Yocto Project and OpenEmbedded engineering. Each skill is self-contained in its own folder and can be shared or used independently.

## Included skills

| Skill | Use it for |
| --- | --- |
| `yocto-layer-engineering` | Creating and integrating layers, machine and distro metadata, overrides, appends, and metadata precedence. |
| `yocto-recipe-maintenance` | Adding or upgrading recipes, managing patches and licenses, dependencies, packaging, and task behavior. |
| `yocto-board-bringup` | Enabling hardware boards and tracing kernel, bootloader, device-tree, firmware, and image artifacts through the boot process. |
| `yocto-build-debugging` | Diagnosing BitBake parse, fetch, task, signature, sstate, packaging, and image build failures. |
| `yocto-release-security` | Release readiness, branch migrations, SBOM and CVE review, license evidence, and reproducible builds. |
| `yocto-version-upgrade` | Planning and implementing release migrations, including compatibility notes, layer impact, staged validation, and upgrade evidence. |

## Use

Each skill folder contains a `SKILL.md` file with its purpose and workflow. In an AI environment that supports this skill format, add the folder using that environment's skill-loading mechanism. The skills can also be read as standalone guidance or adapted for other AI assistants.
